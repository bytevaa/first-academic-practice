# Ludiflex — страница входа и регистрации

Учебный проект: адаптивная форма Login/Sign Up с переключением между двумя состояниями анимацией сдвига. Вёрстка на чистых HTML/CSS, переключение форм и мобильное меню реализованы на JavaScript.

![Превью проекта](images/mountains_snow_slopes_917195_1920x1080.jpg)

## Что реализовано

- Хедер с логотипом, навигационным меню и адаптивной кнопкой-гамбургером
- Переключение между формами Login и Sign Up без перезагрузки страницы (сдвиг блоков + смена стилей кнопок через JS)
- Форма Login: логин/email, пароль, чекбокс "Remember Me", ссылка "Forgot password?"
- Форма Sign Up: имя, фамилия, email, пароль, чекбокс, ссылка на условия использования
- Иконки полей ввода через Boxicons
- Фоновое изображение на всю страницу

## Технологии

- HTML5
- CSS3 (flexbox, адаптивная вёрстка)
- JavaScript (работа с DOM, className, инлайн-стилями)
- Boxicons (иконки)

## Как запустить

Открыть `login.html` в браузере — сборка не требуется.

Либо через локальный сервер:

```bash
npx serve .
```

## Демо

Можно включить бесплатный хостинг через GitHub Pages: Settings → Pages → Source: branch `main`, папка `/ (root)`.
